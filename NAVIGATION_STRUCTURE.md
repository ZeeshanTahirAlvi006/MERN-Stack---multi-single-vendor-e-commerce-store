# Navigation Structure

## Navbar (all users)
- Logo / Store Name
- Search Bar
- Category Links
- Cart Icon (with badge count)
- Auth Section:
  - **[Not logged in]** → Login | Register
  - **[Customer]** → My Orders | Profile | Logout
  - **[Vendor]** → Dashboard | My Products | Sales | Logout
  - **[Admin]** → Admin Panel | Logout

## Sidebar (Vendor Dashboard only)
- Overview
- My Products
- Add Product
- Sales History
- Account Settings
